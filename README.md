# ShopEasy

ShopEasy 是一個專注於提供用戶快速、便利購物體驗的線上電商平台，透過簡單直觀的操作界面、多元化的商品選擇以及快速的物流配送，為用戶帶來無縫的購物體驗。

## 專案簡介

ShopEasy 是一個用戶友好的電商平台，支持多種支付方式和安全的購物環境。

## 功能特性

- **用戶註冊與登錄**：用戶可以輕鬆創建帳戶並安全登錄。
- **產品瀏覽**：支持按類別、價格和評價等條件瀏覽產品。
- **購物車功能**：用戶可以將多個商品添加到購物車，並進行結算。
- **多種支付方式**：支持行動支付、信用卡等多種支付選項。
- **訂單追蹤**：用戶可以即時查看訂單狀態。
