# ShopEasy

ShopEasy 是一個專注於提供用戶快速、便利購物體驗的線上電商平台，透過簡單直觀的操作界面、多元化的商品選擇以及快速的物流配送，為用戶帶來無縫的購物體驗。

### 快速開始

1. `poetry shell` - 啟動 Poetry 虛擬環境，隔離專案依賴套件
2. `poetry install` - 安裝 pyproject.toml 中定義的所有相依套件
3. `npm install`
4. `npm build`
4. `npm serve`
3. `python manage.py runserver` - 啟動 Django 開發伺服器，預設在 http://localhost:8000
